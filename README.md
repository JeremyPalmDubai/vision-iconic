# Vision Iconic Residences

Multilingual static property website for https://vision-iconic-residences.com.

## Hostinger
Deploy the contents of this repository to the domain public_html folder. index.html and .htaccess must be directly inside public_html. No Node server is required.

90 canonical pages across English, French, Spanish, Dutch, German and Portuguese. Includes sitemap, hreflang, localized metadata, brochure imagery, floorplans, AED/USD prices and the Tally enquiry embed.

## Editable source
The source/ folder contains the Python generators, translations and Tailwind configuration. Build instructions are in source/README.md. Generated output goes into source/dist; copy its contents to the repository root after rebuilding.

The website is an independent project presentation. Prices, availability, visa eligibility and offers require confirmation. No lead submission was made during verification.
